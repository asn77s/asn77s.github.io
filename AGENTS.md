# Project instructions

## Website
This is Adrian Nogueira's personal portfolio as an NJIT student.

Pages:
- Home: a short introduction.
- About: my background, education, and interests.
- Projects: Python Gradebook and Random Joke Fetcher with downloadable source and output/workflow images; awaiting a third real project.
- Skills: beginner Python and GitHub experience.
- Contact: public email link.

## Design
- Use a white background, dark gray text, and blue accents.
- Use Arial with a sans-serif fallback.
- Keep the layout simple, clean, and easy to navigate.
- Make the pages work on phones and computers.
- Share styles.css and script.js across all five pages.
- Provide an accessible mobile menu and optional dark mode.

## Rules
- Use plain HTML, CSS, and JavaScript only.
- Do not use frameworks.
- Use relative paths for internal links, images, stylesheets, and scripts.
- Do not include my phone number or home address.
- Do not invent personal achievements, skills, or projects.
- Use semantic HTML and one h1 per page.
- Keep images under 500 KB and provide descriptive alt text.
- Check navigation links and page layout after changes.

## Git
- Commit after each completed task with a clear message.
- Push the commits to GitHub.

## Maintenance
Update this file whenever the website's pages, design, or rules change.
