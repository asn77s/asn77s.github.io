# Project instructions

This is Adrian Nogueira's personal portfolio as an NJIT student.

Pages:
- Home: editorial hero, two featured projects, education, interests, and email.
- About: my background with a Puerto Rico photo, education with a Kearny High School photo and DECA club membership, and interests with Giants, Knicks, and FC Barcelona logo cards.

- Contact: public email link.

## Design
- Use Adrian’s favorite colors: a black background, light text, and red accents.
- Use Impact/Arial Narrow for bold uppercase display headings; Trebuchet MS/Segoe UI for body text.
- Use an editorial black-and-red layout inspired by Adrian’s reference: oversized portfolio lettering, strong headings, project previews, and fine dividers.
- Keep the hero free of the large initials graphic, as requested by Adrian.
- Keep navigation clear and content grounded in Adrian’s actual experience.
- Write clear, confident, natural copy. Describe specific experience without exaggeration or self-deprecating language.
- Make the pages work on phones and computers.
- Share styles.css and script.js across all five pages.
- Provide an accessible mobile menu and optional light mode; black and red is the default.

## Rules
- Use plain HTML, CSS, and JavaScript only.
- Do not use frameworks.
- Use relative paths for internal links, images, stylesheets, and scripts.
- Do not include my phone number or home address.
- Do not invent personal achievements, skills, or projects.
- Use semantic HTML and one h1 per page.
- Keep images under 500 KB and provide descriptive alt text.
- Check navigation links and page layout after changes.

## Git
- Commit after each completed task with a clear message.
- Push the commits to GitHub.

## Maintenance
Update this file whenever the website's pages, design, or rules change.
